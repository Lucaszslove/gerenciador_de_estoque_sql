# 📦 Sistema de Gerenciamento de Estoque

Projeto desenvolvido em Python utilizando SQLite3 para gerenciamento de estoque de produtos.

O sistema funciona via terminal e permite realizar operações de cadastro, visualização, atualização e remoção de produtos armazenados no banco de dados.

---

# 🚀 Tecnologias Utilizadas

- Python 3
- SQLite3

---

# ⚙️ Funcionalidades

✅ Inserir produtos no estoque  
✅ Visualizar produtos cadastrados  
✅ Atualizar quantidade e preço  
✅ Deletar produtos  
✅ Armazenamento persistente com SQLite  

---

# 🗂️ Estrutura do Banco de Dados

Tabela: `estoque_loja`

| Campo | Tipo |
|---|---|
| id | INTEGER |
| nome | TEXT |
| quantidade | INTEGER |
| preco | FLOAT |

---

# ▶️ Como Executar o Projeto

## Clone o repositório

```bash
git clone https://github.com/Lucaszslove/gerenciador_de_estoque_sql
```

---

## Acesse a pasta do projeto

```bash
cd gerenciador_de_estoque_sql
```

---

## Execute o arquivo Python

```bash
python estoque.py
```
